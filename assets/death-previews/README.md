# Death animation reference previews

These 70 transparent GIFs were supplied through the project owner's modified T6MVM library. That library identifies its preview source as Console V4. They depict BO2 animations and are presented as reference material, not as verified BO3 captures.

The animation picker enumerates BO3 assets at runtime. It only shows a GIF when its filename matches the loaded clip's name (without a directory prefix). Missing BO3 previews can be added here as `<clip-name>.gif`; creating BO3-specific captures remains separate work.
